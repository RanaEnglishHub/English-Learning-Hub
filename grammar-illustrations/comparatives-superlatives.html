Comparative & Superlative Adjectives — Complete Lesson

Learn the rules, spelling changes, irregular forms, advanced patterns and common mistakes. Then practise with 20 interactive questions.

Visual pattern: tall → taller than → the tallest of three

Basic meaning

Comparative: compare two people or things (A is taller than B). Superlative: compare one member with a group (A is the tallest in the class). Use than with comparatives; normally use the with superlatives.

One-syllable adjectives

small → smaller → smallest; tall → taller → tallest; fast → faster → fastest. For words ending in -e, add -r/-st: nice → nicer → nicest.

Consonant–vowel–consonant (CVC)

big → bigger → biggest; hot → hotter → hottest; thin → thinner → thinnest. Double the final consonant when the stressed spelling pattern requires it; do not double w, x or y: new → newer → newest.

Adjectives ending in -y

happy → happier → happiest; easy → easier → easiest; busy → busier → busiest. Change consonant + y to i; vowel + y generally keeps y: grey → greyer → greyest.

Two-syllable adjectives

Many adjectives ending in -y take -ier/-iest. Some take -er/-est (clever → cleverer → cleverest; narrow → narrower → narrowest), and others take more/most (careful → more careful → most careful). Some allow both forms: simpler / more simple.

Long adjectives

interesting → more interesting → most interesting; expensive → more expensive → most expensive; reliable → more reliable → most reliable. Do not write “more expensiver.”

Irregular adjectives

good → better → best; bad → worse → worst; far → farther/further → farthest/furthest; little (amount) → less → least; many/much → more → most.

Less and least

less expensive than; the least expensive option. For measurable amounts use less water, but fewer books (countable plural nouns).

Equality and inequality

as + adjective + as: The library is as quiet as the classroom. not as/so + adjective + as: This task is not as difficult as the last one.

Degree modifiers

much/far/a lot + comparative: much faster; a little/slightly + comparative: slightly warmer. Not “very faster”; use “much faster.”

Progressive change

comparative + and + comparative: colder and colder; more and more popular. the + comparative…, the + comparative…: The more you practise, the more confident you become.

Comparing numbers and quantities

more/fewer students than; more/less time than; twice as many books as; three times as much water as.

Superlative patterns

one of the + superlative + plural noun: one of the most useful skills. the second-largest city; by far the best solution; the most interesting book I have ever read.

Common errors

✗ more better → ✓ better; ✗ the most easiest → ✓ the easiest; ✗ taller that → ✓ taller than; ✗ as taller as → ✓ as tall as; ✗ one of the best student → ✓ one of the best students.

Real-life UAE examples

Fujairah is generally cooler than some inland locations in summer. A reusable bottle is often more sustainable than a single-use plastic bottle. Of the three proposals, this is the most practical.
